## 1 · FONT SYSTEM — three things wrong, one thing right

### 1.1 Loading is heavy and miscalibrated
Every client page (foundation/compass/handoff) ships:
- **5 local IBM Plex Sans Arabic weights** (300/400/500/600/700) = ~250 KB blocking before first paint.
- **Google Fonts CSS** importing Instrument Serif (regular + italic) + Inter Tight ×4 weights + JetBrains Mono ×2 = one render-blocking stylesheet + 7 woff2 fetches.
- All `font-display: swap` → visible FOUT on every load.

`index.html` and the three client pages are AR-default but still load the full EN stack at parse time.
`internal/team-hub-ar.html` got this right — JetBrains Mono only, no EN serif/sans.

### 1.2 The five-weight AR ladder is overkill
Real usage by class across all pages: 400 for body, 500 for emphasis, 600 for headings, 700 for masthead. 300 is used **once** (subtitle). 600 and 700 are interchangeable in IBM Plex AR — the visual delta is minimal. Trim to **400 / 500 / 700** = 3 files = ~150 KB. ~100 KB saved per page.

### 1.3 No type scale — twenty ad-hoc sizes per page
Unique `font-size` declarations per file:
- foundation: **65** font-size rules
- compass: **47**
- handoff: **56**
- team-hub-ar: **40**
- index: **16**

Sample bag from foundation: `16, 17, 15, 11, 13, 14, 18, 10.5, 12.5, 14.5, 10, 12, 42, 22, clamp(38,6.2vw,72), clamp(32,5.4vw,56), clamp(26,3.4vw,36), clamp(24,3.2vw,32), clamp(20,2.4vw,26), clamp(19,2.2vw,24)…`

No progression. No rhythm. Each new component invents its own size. This is the visible "fonts are bad" feeling — it's not the typeface, it's the missing scale.

### 1.4 What was right (keep)
- ✅ Self-hosted AR woff2 (commit `50651a8`) — no Google AR CDN dependency. Keep.
- ✅ Early-init script in `<head>` applies theme + dir before first paint — eliminates FOUC. Keep.
- ✅ IBM Plex Sans Arabic — correct family choice for the brand. Keep.

## 2 · DESIGN SYSTEM — the rebuild dropped real signal

Commit `234df74` (today, 19:17) rebuilt the client trio and **silently lost** tokens that were carrying meaning.

### 2.1 Status colors deleted from compass
Old `:root` had a full semantic ladder, both themes:
```
--green / --green-bg   (agree)
--amber / --amber-bg   (refine)
--red   / --red-bg     (disagree)
```
New compass has only `--bronze`. Pigo's "agree / refine" UX has no color signal — every choice now reads the same shade of brown. **Restore.**

### 2.2 Default theme inverted
- **Old:** `:root:not([data-theme="light"])` → defaults to **dark** unless light is forced.
- **New:** `[data-theme="dark"]` → defaults to **light**.

A private bilingual dossier sent to one partner at night reads better default-dark. The old default was the right brand decision. **Revert.**

### 2.3 Container measure widened, hurts AR readability
- Old: `--col: min(640px, 92vw)` · `--col-wide: min(880px, 94vw)`
- New: `--col: min(680px, 92vw)` · `--col-wide: min(960px, 94vw)`

In Arabic, 680px exceeds the 50–75 character comfort band. Tighter column was correct. **Revert.**

### 2.4 Section spacing inflated
- Old: `--sx: clamp(18px, 4vw, 32px)`
- New: `--sx: clamp(20px, 4vw, 40px)` (and `24,4vw,48` on index)

Dense partner pages lost density. The handoff page in particular now reads "marketing site" instead of "private briefing." **Revert.**

## 3 · ARABIC REGISTER — the call is correct, the diagnosis is "Egyptian-literary, not Gulf-institutional"

The rebuild commit explicitly says: *"Arabic register lifted to formal Gulf institutional."*
What actually shipped is **formal Egyptian literary MSA** — the Al-Ahram editorial register, not the Mubadala / ADIA / RTA institutional register.

### 3.1 Evidence — current AR samples
```
"ثلاث صفحات من قراءةٍ متأنّية. الأساس، البوصلة، التسليم. تَحمل، مجتمعةً، …"
"هذه مرآة. تعكس ما فهمناه عن كاتاليست بارتنرز — بعد تنقيحه بقراءة السوق وصقله بما تعلمناه. ليست عرضاً تجارياً"
"هل قرأناكم بصورةٍ صحيحة؟"
"أربع قراءات. أكِّدوا أو هذِّبوا."
"تَحمل، مجتمعةً، ما فهمناه عن الشركة"
"بعد تنقيحه بقراءة السوق وصقله بما تعلمناه"
```

### 3.2 Why this reads "Egyptian" not "Gulf"
1. **Heavy tashkeel on common words** — "قراءةٍ" "متأنّية" "مجتمعةً" "تَحمل" — Gulf institutional Arabic strips diacritics on common nouns; tashkeel is reserved for disambiguation only.
2. **Literary metaphors leading propositions** — "هذه مرآة" / "تعكس ما فهمناه" / "بعد تنقيحه وصقله" — this is Cairo-editorial register. Gulf docs open with the proposition, not the simile.
3. **Inverted word order for rhythm** — "تَحمل، مجتمعةً، ما فهمناه" — rhythmic prose, Egyptian literary tradition. Gulf institutional is verb-first declarative.
4. **Plural pronoun "كم"-forms in command voice** — "أكِّدوا أو هذِّبوا" / "قرأناكم" — Egyptian formal address. Gulf uses "تفضّلوا بـ…" / "نرجو تأكيد…" / "يُرجى" forms.
5. **Marker words** — "صقله" "تنقيحه" "مُخرَج" — Egyptian translation-school lexicon. Gulf institutional prefers "النسخة" / "التعديل" / "المُنتَج" / "المُخرَجات".

### 3.3 The target register — UAE institutional advisory
Reference templates: RTA / Mubadala / ADIA / Strategy& (ME) Arabic decks. Characteristics:
- **No tashkeel** except on the entity name and one or two technical terms per page.
- **Verb-first or noun-first declarative**, no rhythmic inversion.
- **Plain modal address**: "نعرض" / "نقترح" / "نطلب تأكيدكم" — no "أكِّدوا".
- **Sentence length ≤ 18 words**, often ≤ 12. Current text averages 25+ word sentences.
- **Numerals in Western form** (already enforced, ✅).
- **No similes / metaphors** in body copy; metaphors go in the masthead only.

### 3.4 Concrete rewrite examples
| Page | Current (Egyptian-literary) | Proposed (Gulf-institutional) |
|---|---|---|
| index hero | ثلاث صفحات من قراءةٍ متأنّية. الأساس، البوصلة، التسليم. تَحمل، مجتمعةً، ما فهمناه عن الشركة — وما نقترح بناءه قبل أن نبدأ بأوّل مُخرَج. | ثلاث صفحات. الأساس، البوصلة، التسليم. نعرض فيها ما فهمناه عن الشركة، وما نقترح بناءه قبل البدء بأي مُخرَجات. |
| foundation lead | هذه مرآة. تعكس ما فهمناه عن كاتاليست بارتنرز — بعد تنقيحه بقراءة السوق وصقله بما تعلمناه. ليست عرضاً تجارياً، | هذا ملخّص ما فهمناه عن كاتاليست بارتنرز، بعد مراجعة السوق وتعديله بناءً على ما تعلّمناه. ليس عرضًا تجاريًا. |
| compass prompt | هل قرأناكم بصورةٍ صحيحة؟ — أربع قراءات. أكِّدوا أو هذِّبوا. | أربع قراءات نطلب تأكيدها أو تعديلها. |
| compass CTA | اتّخذنا أربع قراءات عن كاتاليست — في التموضع، في القطاع الأول، في الاسم العربي، وفي لحظة البدء. | أربع قراءات: التموضع، القطاع الأول، الاسم العربي، لحظة البدء. |

Same meaning, ~40% fewer words, no diacritics, no metaphors. Reads like an institutional brief, not an editorial.

## 4 · WHAT I PROPOSE TO FIX (in this order)

1. **Type scale + font load** — add a shared `system.css` (or inline `:root` block) with one fluid type scale `--t-1…--t-7`, replace ad-hoc sizes file-by-file. Drop AR weights to 400 / 500 / 700. Remove Inter Tight `300` and `600` (use 400 + 500). Move Google Fonts to `media="print" onload` swap to un-block first paint.
2. **Restore lost tokens** — bring back `--green/-bg`, `--amber/-bg`, `--red/-bg` (light + dark). Revert `--col` 640/880, `--sx` 18/32, default-dark theme.
3. **Rewrite AR copy** — page by page, in Gulf-institutional register, against the rewrite rules in §3.3. Keep the EN copy as-is; the brief stays bilingual but Arabic stops sounding Egyptian.
4. **Re-audit** — one pass after each step, verify nothing else regressed.

Each step is a separate commit, reviewable in isolation.
